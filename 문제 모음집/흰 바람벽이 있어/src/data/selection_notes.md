## 제외 항목

### 정답 키 결함
- **s01-14**: 해설 ②가 오답 선지를 “볼 수 있다”로 서술해 정답 ⑤와 모순됨.
- **s03-9**: 정답은 ③(우물)인데 해설이 “④의 ‘우물’”이라 적고 ④를 따로 설명함. 해설과 정답이 어긋남. 같은 유형인 s01-9를 대신 씀.
- **s03-18**: 정답이 “③, ④”로 복수 정답이라 단일 정답이 아님.
- **s03-19**: 선지 ①과 ②가 둘 다 ‘ㄱ’이라 선지가 깨져 있음.

### 중복과 유사 문항
- 완전히 같은 문항(발문과 선지 일치)은 파일 사이에 없음.
- **s05-4 제외**: s03-5와 거의 같다. 발문이 같고 선지 3개(감각적 심상, 토속적 시어, 수미상관)와 정답(수미상관)도 같다. 최근 판(2024년판 01)인 s03-5를 남김.
- **s01-10 선정, s02-19 미선정**: 같은 2025년판 안에서 화자 설명 선지 3개가 겹친다. 하나만 씀.

### 키는 유효하지만 선정에서 뺀 것
- s02-18: 정답 ①(‘타향에서 느끼는 곤궁함과 고립’)이 틀린 이유를 해설이 직접 설명하지 않아 키 근거가 약함.
- s02-27: <보기> ㅁ(‘현실에 저항하고 적극적으로 극복’)을 적절하다고 보는 키가 작품 해석상 논란이 될 수 있음.
- s02-25: 선지 ①에 ‘ⓑ, ⓒ, ⓒ’ 오기가 있음.
- s03-4: 해설 ② 자리에 정답 ⑤의 근거가 잘못 들어가 있음.
- s04-20: ⑤의 ‘체념’ 해석이 같은 자료의 다른 해설과 엇갈림.
- s06-17, s06-18: 원래 파트에서 skip된 문항(윤동주 시만 다룸).
