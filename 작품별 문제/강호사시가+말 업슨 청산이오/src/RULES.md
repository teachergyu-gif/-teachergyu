## 표기 규칙
- 글자 하나하나 원본 그대로. 맞춤법을 임의로 고치지 말 것. 원본 오류로 보이는 것은 고치지 말고 "issues"에 적는다.
- 옛한글은 유니코드 첫가끝 조합으로: 아래아 ᆞ(U+119E), ᆡ(U+11A1), 예: ᄒᆞ = "ᄒᆞ", ᄃᆞᆯ = "ᄃᆞᆯ", ᄆᆞᄅᆞᆯ 등.
  ㅿ(ᅀ U+1140), ㆁ(ᅌ U+114C), ㆆ(ᅙ U+1159) 등도 같은 방식. 받침은 U+11A8~ 종성 자모.
  사이시옷 'ㅅ' 단독 표기는 'ㅅ'(U+3145).
- 밑줄: <u>…</u>, 굵게: <b>…</b>, 기호(㉠㉡ ⓐⓑ Ⓐ [A] 등)는 원본 위치 그대로. 빈칸 표시는 원본 모양대로(예: ( ㉮ ), [  ]).
- 따옴표는 원본처럼 ‘ ’ “ ” 를 쓴다.
- 줄바꿈: 시·시조 지문은 원본 행 그대로 "\n", 연 구분은 빈 줄("\n\n"). 산문(보기, 해설, 줄글 지문)은 원본 단 너비 때문에 생긴 줄바꿈은 없애고 이어 쓴다(문단 바뀜만 "\n").
- 단이 넘어가며 끊긴 지문은 이어 붙인다(원본에서 줄이 중복되면 issues에 적고 한 번만).

## 출력: UTF-8 JSON 파일 (ensure_ascii=False). 작업 끝나면 python으로 json.load 검증까지.
