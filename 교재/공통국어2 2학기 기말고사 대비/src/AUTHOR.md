# 정답·해설·지문 분석 작성 기준 (공통국어2 기말 대비 교재)

입력: /tmp/claude-0/-home-user/cac8e88e-55f6-555b-a091-e2222438c3e6/scratchpad/gk/work/<파트>/out.json (전사본; 원본 사진은 scratchpad/gk/img/p01~p10.jpg — 의심스러우면 확인)
원본엔 정답·해설이 없다 → 지문 근거로 직접 풀어서 작성한다. 한 문항씩 모든 선지를 지문과 대조해 검증하고, 정답이 둘이거나 없는 문항(출제 오류)은 issues에 적고 가장 타당한 답을 고른다.

## 출력 1: work/<파트>/answers.json  (키 = str(orig), 예 "1", "서답형 3")
객관식: {"answer": "③", "correct": "정답 선지 해설(왜 맞는/틀린지, 지문 근거 인용 ‘…’)", "wrong": [["①","…"],["②","…"],["④","…"],["⑤","…"]]}
 - 발문이 '적절하지 않은 것'이면 correct는 왜 적절하지 않은지, wrong은 각각 왜 적절한지.
 - 해설 문장은 '~이다/~한다/~므로 적절하다' 체. 각 1~2문장, 지문 근거를 작은따옴표로 인용(인용은 지문 글자 그대로).
서답형: {"answer": "모범 답안(조건을 모두 지킨 완성 답안, 여러 개면 \n로)", "points": ["채점 기준1", "…"], "plain": "해설 1~3문장"}
 - <조건>의 글자 수·형식(문장 수, 어절, '~함' 등)을 정확히 지킨다.

## 출력 2: work/<파트>/analysis.json  (키 = 지문 묶음 번호 "1"~"7": 1 매체의 발달, 2 사이버 레커, 3 협상, 4 금융 이해력, 5 마녀사냥(가)(나)(다), 6 매카시즘(가)(나), 7 제정신이라는 착각(가)(나))
{"<번호>": {"works": [ {"label": "(가)"(작품 하나면 ""), "title": "글 제목/화제", "topic": "주제 한 문장",
   "structure": "글의 구조 한 줄(예: 문제 제기 → 원인 분석 → 해결 방안)",
   "paras": [{"n": 1, "summary": "1문단 요약 1~2문장"}, …],   ← 문단 = 지문 lines의 줄(빈 줄·<b>소제목</b>줄·(1)(2) 항목줄 제외 산문 줄) 순서대로 1,2,3… (교재에 이 번호가 붙음). 대화문(협상)은 발화 줄 하나가 한 문단.
   "vocab": [["어휘", "뜻"], …] 4~8개(지문 속 밑줄 어휘·한자어·개념어),
   "points": ["시험 출제 포인트", …] 3~6개 } ]}}
 - 협상 지문은 structure에 협상 단계(시작-조정-해결), points에 양측 입장·전략. 

## 공통
- JSON UTF-8 ensure_ascii=False, json.load로 검증. 표기는 ‘ ’ “ ” 사용. 오탈자·띄어쓰기 점검.
- 끝나면 보고: 문항별 정답 목록, 출제 오류 의심 문항, 원본 오탈자.
