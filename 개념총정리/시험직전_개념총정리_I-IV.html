I. 음운 변동한눈에 끝!

음운 변동 = 이웃한 음운의 영향으로 소리가 바뀌는 것 (발음의 경제성!)

교체A → B

끝소리 규칙, 비음화, 유음화, 구개음화, 된소리되기, 반모음화

탈락AB → A

자음군 단순화, ‘ㄹ’·‘ㅎ’·‘ㅡ’·‘ㅏ/ㅓ’ 탈락

축약A+B → C

거센소리되기, 모음 축약

첨가A → AB

‘ㄴ’ 첨가, 반모음 첨가

한 단어에서 두 가지 이상의 변동이 연쇄적으로 일어나기도 함

1교체한 음운 → 다른 음운  ·  비음화·유음화·구개음화 = 동화(이웃 소리를 닮아 감)

1

음절의 끝소리 규칙 — 받침 소리는 ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ 7개뿐!

ㄲ·ㅋ → [ㄱ] / ㅅ·ㅆ·ㅈ·ㅊ·ㅌ·ㅎ → [ㄷ] / ㅍ → [ㅂ]   낫·낮·낯·낱 → 모두 [낟]

연음 주의+ 형식 형태소(조사·어미·접미사) → 바로 연음  옷이[오시], 꽃이[꼬치]

+ 실질 형태소 → 대표음 먼저, 그다음 연음  옷 안[오단], 꽃 위[꼬뒤]

2

비음화 — ㄱ·ㄷ·ㅂ + ㄴ·ㅁ → [ㅇ·ㄴ·ㅁ]  국물[궁물], 닫는[단는], 밥물[밤물]

조음 위치는 그대로, 조음 방법만 바뀜 (유음화도 같음)

‘ㄹ’의 비음화: ㅁ·ㅇ + ㄹ → [ㄴ]  종로[종노], 담력[담ː녁]

ㄱ·ㄷ·ㅂ + ㄹ → ㄹ이 먼저 [ㄴ], 그다음 앞 받침도 비음화  독립[독닙→동닙]

3

유음화 — ㄴ + ㄹ, ㄹ + ㄴ → [ㄹㄹ]  신라[실라](역행), 칼날[칼랄](순행)

4

구개음화 — 받침 ㄷ·ㅌ + ‘ㅣ’로 시작하는 형식 형태소 → [ㅈ·ㅊ]

굳이[구지], 밭이[바치] / ㄷ + 접미사 ‘-히-’ → 닫히다[다티다→다치다]

조음 위치와 조음 방법이 모두 바뀜

✕ 잔디·디디다(한 형태소 안), 곧이어[고디어](뒤가 실질 형태소)

5

된소리되기 — 예사소리 ㄱ·ㄷ·ㅂ·ㅅ·ㅈ → 된소리, 환경 5가지

① 받침 ㄱ·ㄷ·ㅂ 뒤: 국밥[국빱], 옷고름[옫꼬름], 입술[입쑬]

② 어간 받침 ㄴ(ㄵ)·ㅁ(ㄻ) + 어미: 신고[신ː꼬], 앉고[안꼬], 삼고[삼ː꼬]  ※ 안기다 ✕(접미사)

③ 어간 받침 ㄼ·ㄾ + 어미: 넓게[널께], 핥다[할따]

④ 관형사형 어미 ‘-(으)ㄹ’ 뒤: 할 것을[할꺼슬], 만날 사람[만날싸람]

⑤ 한자어 ‘ㄹ’ 받침 뒤 ㄷ·ㅅ·ㅈ: 갈등[갈뜽], 일시[일씨], 발전[발쩐]

6

반모음화 — 단모음 → 반모음  피- + -어서 → 펴서, 보- + -아 → 봐 표기 O

2탈락원래 있던 음운이 없어짐

1

자음군 단순화 — 겹받침은 어말·자음 앞에서 하나만 발음

앞 자음 탈락 ㄺ·ㄻ·ㄿ: 닭[닥], 삶[삼ː], 읊다[읍따]

뒤 자음 탈락 ㄳ·ㄵ·ㄼ·ㄽ·ㄾ·ㅄ: 넋[넉], 앉다[안따], 여덟[여덜], 값[갑]

예외 콕맑게[말께](용언 ㄺ + ㄱ), 밟다[밥ː따], 넓죽하다[넙쭈카다]

+ 모음 형식 형태소 → 단순화 없이 연음  닭을[달글], 넋이[넉씨]

+ 모음 실질 형태소 → 단순화 후 연음  닭 앞에[다가페], 넋 없다[너겁따]

ㄶ·ㅀ + ㅅ·ㄴ → 자음군 단순화  많소[만ː쏘], 많니[만ː니]

+ 모음 형식 형태소 → ‘ㅎ’ 탈락  많아[마ː나]

2

‘ㄹ’ 탈락 — 어간 끝 ㄹ + ㄴ·ㅂ·ㅅ 어미  살- + -니 → 사니, 알- + -시- + -고 → 아시고 표기 O

3

‘ㅎ’ 탈락 — 어간 끝 ㅎ + 모음 형식 형태소  놓아[노아], 좋은[조ː은], 끓이다[끄리다]

4

‘ㅡ’ 탈락 — 어간 끝 ‘ㅡ’ + 모음 어미  쓰- + -어 → 써, 잠그- + -아 → 잠가 표기 O

5

‘ㅏ/ㅓ’ 탈락 — 어간 끝 ‘ㅏ/ㅓ’ + ‘ㅏ/ㅓ’ 어미  가- + -아서 → 가서, 서- + -어라 → 서라 표기 O

3축약두 음운이 합쳐져 하나로

1

거센소리되기 — ㄱ·ㄷ·ㅂ·ㅈ + ㅎ → [ㅋ·ㅌ·ㅍ·ㅊ] (ㅎ이 앞이든 뒤든 OK)

국화[구콰], 잡히다[자피다], 놓다[노타], 많지[만ː치]

순서 주의단어 사이에선 앞 단어 변동이 먼저  옷 한 벌[옫한벌→오탄벌]

닭 한 마리[닥한마리→다칸마리]  [달칸마리] ✕

단, 용언 어간 + 접미사는 곧바로 축약  꽂히다[꼬치다], 넓히다[널피다]

2

모음 축약 — 단모음 + 단모음 → 다른 단모음  보이다 → 뵈다, 사이 → 새, 누이다 → 뉘다 표기 O

4첨가없던 음운이 새로 생김

1

‘ㄴ’ 첨가 — 합성어·파생어에서 자음 + ‘이, 야, 여, 요, 유’

맨입[맨닙], 솜이불[솜ː니불], 한여름[한녀름], 식용유[시굥뉴]

첨가된 ㄴ 때문에 → 비음화  색연필[색년필→생년필], 꽃잎[꼳닙→꼰닙]

첨가된 ㄴ 때문에 → 유음화  서울역[서울녁→서울력], 물엿[물녇→물렫]

↳ ‘ㄹ’이 한 번에 첨가된 게 아님!

2

반모음 첨가 — 되어[되어/되여], 피어[피어/피여] (일부만 허용)

1높임 표현높이는 대상에 따라 주체 · 객체 · 상대 높임

1

주체 높임 — 서술의 주체(주어)를 높임: 께서, -님, -(으)시-

특수 어휘: 계시다, 주무시다, 잡수시다, 댁, 진지, 성함  할아버지께서 낮잠을 주무셔.

간접 높임: 주체의 신체·소유물 등을 높여 주체를 높임  할머니께서는 귀가 밝으시다.

주의‘계시다’는 주체를 직접 높일 때만 → 무슨 고민 계세요?(✕) / 고민 있으세요?(O)

2

객체 높임 — 목적어·부사어의 대상을 높임: 조사 ‘께’, 뵙다, 모시다, 드리다, 여쭙다

나는 아버지를 모시고 병원에 갔다. / 할머니께 인사를 드렸다.

2시간 표현발화시(말하는 때) 기준, 사건시는 언제?

1

과거 (사건시 < 발화시) -았/었-, -았었/었었-(현재와 단절), -더-(회상), -(으)ㄴ(동사), -던

현재 (사건시 = 발화시) -ㄴ/는-(동사), 형용사는 기본형 / -는(동사), -(으)ㄴ(형용사)

미래 (사건시 > 발화시) -겠-, -(으)ㄹ, -(으)ㄹ 것  + 시간 부사어(어제·지금·내일)

2

다른 뜻도 있어요 — -었-: 완결 지속 엄마를 닮았어요 / -는-: 진리 물은 0℃에서 언다

-겠-: 추측 벌써 끝냈겠다, 의지 시인이 되겠다, 가능성, 완곡한 태도

3

동작상 — 진행상: -고 있다, -아/어 가다, ‘중’ / 완료상: -아/어 있다, -어 버리다, ‘채’

중의성나는 안경을 쓰고 있다 → 쓰는 중(진행) / 쓴 상태가 지속(완료)

3피동 표현주어가 다른 대상에 의해 동작을 당함

1

능동문 → 피동문 — 목적어 → 주어, 주어 → 부사어(에게/에, 한테, 에 의해)

명수가 도둑을 잡다. → 도둑이 명수에게 잡히다.

2

파생적(단형) 피동 — 동사 어근 + -이-, -히-, -리-, -기-  보이다, 업히다, 물리다, 쫓기다

일부 명사 + -되다(‘-하다’ 대신)  정리되다, 발견되다

※ 피동사는 새 단어! ‘보였다’의 기본형은 ‘보다’가 아니라 ‘보이다’

3

통사적(장형) 피동 — 용언 어간 + -아/어지다, -게 되다  구겨지다, 미뤄지다, 가게 되다

형용사 + -아/어지다 = 상태 변화  날씨가 따뜻해졌다

4

더 알아 둘 것 — 짝이 되는 능동문이 없는 피동문도 있음  날씨가 풀리다

행위 주체를 감추거나, 당한 대상·결과를 강조하고, 객관성을 높일 때 → 보도문·학술문에 많음

5

이중 피동 ✕ — 피동 접미사·‘-되다’ + ‘-어지다’를 겹쳐 씀

보여진다 → 보인다, 열려지지 → 열리지, 믿겨지지 → 믿기지, 생각되어진다 → 생각된다

6

사동과 헷갈리지 않기 — 사동: 주어가 남에게 어떤 행동을 하게 함

동생이 옷을 입다.(주동) → 어머니께서 동생에게 옷을 입힌다.(사동)

4인용 표현남의 말이나 글을 끌어다 씀

1

직접 인용 — 원래 형식·내용 그대로, 큰따옴표(“ ”) + ‘라고’ (현장감, 발언 강조)

(쉽게), (마음), (만드니)

5

모음 조화 — 양성은 양성끼리, 음성은 음성끼리 잘 지켜짐   / 너는, 자바 / 블거

6

3중세 국어의 문법체언 · 조사 · 어미

1

ㅎ 종성 체언 — ‘ㅎ’을 끝소리로 가진 체언

모음이나 ‘ㄱ, ㄷ’으로 시작하는 조사 앞에서만 ㅎ 실현

나라ㅎ + 이 → 나라히, 나라ㅎ + 과 → 나라콰 / 단독·‘ㅅ’ 앞에선 ✕ 나라, 나랏

현대어에 남은 흔적: (암탉), (안팎), (살코기)

2

주격 조사 — ‘이, ㅣ, ∅’  (주격 조사 ‘가’는 없음! → 근대 국어 이후 등장)

이자음노미(놈 + 이)

∅‘ㅣ’나 반모음 ‘ㅣ’불휘(불휘 + ∅) [뿌리가]
3

목적격 조사 — 받침 O: /을, 받침 X: /를 — 모음 조화에 따라

(마음을), (뜻을), 부텨를(부처를)

4

관형격 조사 — /의: 유정 명사(사람·동물)  (남의), 거부븨(거북의)

ㅅ: 높임 대상인 유정 명사 부텻(부처의), 무정 명사 나랏(나라의), 나못(나무의)

5

부사격 조사 — 애(양성) (바다에) / 에(음성) 그르세 / 예(‘ㅣ’ 뒤) 萬里예

6

그 밖에 — 높임의 호격 조사 ‘하’ 님금하(임금이시여) / 명사형 어미 ‘-옴/-움’ 여룸(열림), (씀에)

IV. 한글 맞춤법소리 · 형태 · 띄어쓰기

총칙제1항 표준어를 소리대로 적되, 어법에 맞도록 함을 원칙으로 한다.  제2항 각 단어는 띄어 씀.

소리대로 = 발음대로 / 어법에 맞도록 = 형태소 본모양을 밝혀 (꽃을·꽃도·꽃만)

1소리에 관한 것

1

된소리제5항 — 한 단어 안에서 까닭 없이 나는 된소리는 된소리로

모음 사이 어깨, 오빠, 기쁘다 / ㄴ·ㄹ·ㅁ·ㅇ 뒤 산뜻하다, 잔뜩, 살짝, 몽땅

다만ㄱ·ㅂ 뒤는 예사소리 국수, 깍두기, 갑자기, 몹시 (반복 음절은 딱딱)

2

구개음화제6항 — [ㅈ, ㅊ]으로 소리 나도 ㄷ, ㅌ으로  맏이, 해돋이, 같이, 닫히다

3

ㄷ 소리 받침제7항 — ㄷ으로 적을 근거가 없으면 ㅅ으로  돗자리, 웃어른, 옛, 첫, 헛

4

모음제8·9항 — 계·례·몌·폐·혜는 ㅖ로 계시다, 폐품 (다만 게시판, 휴게실)

‘의’, 자음 뒤 ‘ㅢ’는 [ㅣ]로 소리 나도 ㅢ로 무늬, 띄어쓰기, 희망

5

두음 법칙제10~12항 — 한자음이 단어 첫머리에 올 때

녀·뇨·뉴·니 → 여·요·유·이 여자, 연세

랴·려·례·료·류·리 → 야·여·예·요·유·이 양심, 역사

라·래·로·뢰·루·르 → 나·내·노·뇌·누·느 노인

첫머리 아님·의존 명사는 본음 남녀, 몇 년

주의모음·ㄴ 뒤 ‘렬, 률’ → 열, 율 나열, 비율, 백분율 vs 합격률, 능률

접두사처럼 쓰인 한자·합성어는 두음 법칙대로 신여성, 공염불, 역이용, 해외여행

2형태에 관한 것원형을 밝혀 적을까, 소리대로 적을까?

1

어간과 어미제15항 — 구별하여 적음

두 용언이 합쳐질 때 앞말 본뜻 유지 → 원형 넘어지다, 돌아가다

본뜻에서 멀어짐 → 소리대로 드러나다, 사라지다, 쓰러지다

종결 ‘-오’ 책이오 / 연결 ‘이요’ 책이요, 저것은 / 조사 ‘요’ 읽어요

2형태에 관한 것(이어서)

2

명사·부사 만들기제19항 — 어간 + -이·-음(명사), -이·-히(부사) → 원형

길이, 먹이, 얼음, 묶음, 많이, 익히 / 뜻이 멀어지면 소리대로 목거리(병), 노름

그 밖의 모음 접미사가 붙으면 소리대로 마개, 무덤, 너무, 자주

3

‘-하다’ 어근 + -이/-히제23·25항 → 원형 꾸준히, 깨끗이, 반듯이(바르게)

‘-하다’가 안 붙으면 소리대로 반드시(꼭), 갑자기 / 명사: 오뚝이 vs 개구리

4

‘ㄹ’이 안 나는 말제28항 — 안 나는 대로 다달이, 따님, 마소, 바느질, 여닫이

5

사이시옷제30항 — 합성어, 앞말이 모음으로 끝남, 고유어 포함, 뒷말이 된소리·‘ㄴ’·‘ㄴㄴ’ 덧남

고유어 + 고유어 나뭇가지, 햇볕, 잇몸, 깻잎 / 고유어 + 한자어 귓병, 전셋집, 훗날, 예삿일

✕ 합성어가 아님 해님 / 뒷말이 된소리·거센소리 위층, 뒤편 / 한자어끼리 초점, 개수

예외두 음절 한자어 6개만 사이시옷: 곳간, 셋방, 숫자, 찻간, 툇간, 횟수

6

준말제35·40항 — 쏘아 → 쏴, 두었다 → 뒀다, 놓아 → 놔, 뵈어 → 봬

‘하’ 앞이 울림소리·모음 → ‘ㅎ’이 남아 거센소리 간편케, 다정타, 흔타

‘하’ 앞 받침소리가 [ㄱ, ㄷ, ㅂ] → ‘하’가 통째로 줄어 생각건대, 넉넉지, 깨끗지

3띄어쓰기

1

조사는 붙여제41항 꽃에서부터 / 의존 명사는 띄어제42항 아는 것, 떠난 지

2

단위 명사는 띄어제43항 차 한 대, 옷 한 벌 (순서·숫자와는 붙여도 됨 10개)

3

보조 용언제47항 — 띄어 씀이 원칙, 붙여 씀도 허용 꺼져 간다(꺼져간다), 올 듯하다(올듯하다)

앞말에 조사·앞말이 합성 용언·중간에 조사 → 띄어야 읽어도 보고, 덤벼들어 보아라, 올 듯도 하다

4그 밖의 것

1

-이 / -히제51항 — ‘이’로만 나면 -이 깨끗이, 가까이, 번번이

‘히’나 ‘이·히’로 나면 -히 급히, 솔직히, 꼼꼼히

2

예사소리 어미제53항 -(으)ㄹ걸, -(으)ㄹ게, -(으)ㄹ수록 / 의문은 된소리 -(으)ㄹ까?, -(으)ㄹ쏘냐?

3

-던 vs -든지제56항 — 지난 일 -더라, -던 깊던 물 / 선택 -든지 배든지 사과든지
